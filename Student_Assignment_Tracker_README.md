# Student Assignment Tracker

A full-stack web application for managing student assignments, deadlines, priorities, and progress status.

## Live links
- Frontend: https://akshay225725-bit.github.io/student-assignment-tracker/
- GitHub repository: https://github.com/akshay225725-bit/student-assignment-tracker
- Backend health: https://student-assignment-tracker-api-ut5n.onrender.com/api/health
- Assignments API: https://student-assignment-tracker-api-ut5n.onrender.com/api/assignments

## Technology stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB Atlas through Mongoose
- Frontend hosting: GitHub Pages (GitHub Actions)
- Backend hosting: Render

## Features
- Create, list, edit, and delete assignments
- Assignment fields: title, description, due date, status, and priority
- Dashboard counts for total, pending, in-progress, and completed work
- Search by title or description and filter by status
- Persistent assignment records in MongoDB Atlas

## Local development
1. Install Node.js and npm.
2. In `server/`, run `npm install`. Create `server/.env` with `MONGODB_URI=<your MongoDB Atlas connection string>`. Never commit `.env`.
3. Start the backend from `server/` with `npm start`.
4. In another terminal, go to `client/`, run `npm install`, then `npm run dev`.
5. For local development, configure the frontend API URL to `http://localhost:5000/api/assignments`; for the deployed version use the Render URL shown above.

## API endpoints
| Method | Route | Purpose |
|---|---|---|
| GET | `/api/health` | API health check |
| GET | `/api/assignments` | List assignments |
| GET | `/api/assignments/:id` | Get one assignment |
| POST | `/api/assignments` | Create assignment |
| PUT | `/api/assignments/:id` | Update assignment |
| DELETE | `/api/assignments/:id` | Delete assignment |

## Assignment fields
`title` (required), `description`, `dueDate`, `status` (`Pending`, `In Progress`, `Completed`), and `priority` (`Low`, `Medium`, `High`). Mongoose timestamps add `createdAt` and `updatedAt`.

## Deployment notes
- Render root directory: `server`; build command: `npm install`; start command: `npm start`.
- Set `MONGODB_URI` in Render environment variables.
- GitHub Pages uses the `client/dist` build generated by GitHub Actions.
- The Express app must enable CORS for the GitHub Pages origin before registering routes.
